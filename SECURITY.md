# Security Policy

## Supported Versions
Only the latest release gets security fixes.

## Report a Vulnerability
Please do NOT open a public issue.
Use GitHub: Security tab -> "Report a vulnerability".
Or email: chris@catho.de

Include: what you found, steps to repeat, version.
I reply within 7 days. I fix, then credit you if you want.

## Scope
WealthView runs on your own computer. Data stays local.
In scope: bugs that leak data, credentials, or run bad code.
Out of scope: attacks needing full access to your machine.

## Keep Yourself Safe
- Never commit bank data, CSV, PayPal, Coinbase files, or API keys.
- Never share your FinTS PIN or login.
- Keep data folders out of Git (use .gitignore).
- Download installers only from the official GitHub Releases page.
